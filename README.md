# Warehouse Management System

Консольное приложение на C++20 для управления складским учётом электронных устройств. Проект спроектирован с соблюдением принципов объектно-ориентированного программирования (ООП) и SOLID-архитектуры.

---

## Основные возможности

* **Просмотр каталога:** Вывод полного списка товаров, их характеристик, остатков на складе и стоимости.
* **Добавление товаров:** Регистрация новых позиций (смартфоны, планшеты, ноутбуки, бытовая техника). При добавлении существующей модели её количество автоматически суммируется.
* **Удаление и списание:** Быстрое удаление позиций со склада или изменение (пополнение/списание) количества товара.
* **Редактирование:** Интерактивное подменю для изменения параметров конкретного устройства.
* **Поиск и сортировка:** Просмотр подробной информации по модели и сортировка каталога по цене (от дешёвых к дорогим).
* **Сохранение и загрузка состояния:** Сериализация и десериализация всех данных склада и истории операций в текстовые файлы сохранений.
* **Логирование действий:** Автоматическая запись всех операций склада в файл журнала (`journal.log`) с меткой времени.
* **Генерация отчётов:** Выгрузка структурированных форматированных отчётов (`report.txt`) с подсчётом суммарной стоимости, количества SKU и группировкой по категориям.

---

## Особенности архитектуры и C++20

* **Соблюдение SOLID (SRP):** Логика работы с файловыми потоками, сериализация и формирование отчётов выделены из бизнес-логики (`Warehouse`) в специализированный сервисный класс `WarehouseFileManager`.
* **Полиморфизм и иерархия классов:** Базовый класс `ElectronicDevice` и дочерние классы (`Smartphone`, `Tablet`, `Laptop`, `HomeAppliance`) с переопределением потокового ввода-вывода (`saveToFile` / `loadFromFile`).
* **Современный C++20:**
  * Использование трехстороннего сравнения `<=>` и концепции *hidden friends*.
  * Безопасное форматирование строк с помощью библиотеки `<format>`.
  * Использование стандартных алгоритмов и диапазонов (`std::ranges`).
  * Полная обработка исключений (кастомный иерархический класс `Exceptions`).
