# Warehouse Management System
Консольное приложение на C++ для управления складским учетом электронных устройств. Проект спроектирован с использованием принципов модульной архитектуры и разделением на заголовочные файлы и файлы реализации.

## Основные возможности

* **Просмотр каталога:** Вывод списка всех товаров, их остатков и цен на складе.
* **Добавление товаров:** Регистрация новых позиций. Если товар с такой моделью уже есть, его количество на складе автоматически суммируется.
* **Удаление товаров:** Быстрое удаление позиций со склада.
* **Редактирование:** Интерактивное подменю для изменения характеристик конкретного товара.
* **Поиск товара:** Просмотр подробной информации и актуального остатка по конкретной модели.
* **Сортировка:** Сортировка товаров по цене (от дешевых к дорогим).

## Особенности проекта

* Разделен на логические модули (заголовочные файлы `.h` и файлы реализации `.cpp`).
* Написан с использованием современных возможностей C++20 (трехстороннее сравнение `<=>`, модули `std::ranges`, скрытые друзья `hidden friends`).
