## Функционал программы

1. **Просмотр каталога:** Вывод списка всех товаров на складе с указанием остатков, цен и характеристик.
2. **Добавление товаров:** Регистрация новых позиций (тип, модель, производитель, цена, гарантия, количество, доп. характеристики). Если товар с такой же моделью и производителем уже существует, программа автоматически суммирует остатки.
3. **Редактирование характеристик:** Интерактивное подменю для выборочного изменения свойств товара по его модели.
4. **Просмотр отдельных характеристик:** Быстрый поиск и вывод детальной информации по конкретной модели.
